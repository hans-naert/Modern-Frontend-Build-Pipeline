# Modern Frontend Build Pipeline
## Hands-on met esbuild
- Voltooi de volgende tutorial: [Getting Started with esbuild (Better Stack Community)](https://betterstack.com/community/guides/scaling-nodejs/esbuild-explained/).
- Voeg een afbeelding toe aan je project.
- Maak gebruik van het esbuild content type [Data URL](https://esbuild.github.io/content-types/) voor de afbeelding en onderzoek hoe deze wordt gebundeld.

## Hands-on Workbox
- Maak met behulp van esbuild en Workbox een serviceworker aan via injectManifest. Voeg een lijst met afbeeldingen toe aan je app en controleer of deze correct worden geprecached. Voeg vervolgens een application manifest toe en test of de app installeerbaar is en offline functioneert.
